# eJudge 3.14.0 + 1С:Предприятие.Элемент Скрипт 10.0.2-1

Этот форк основан на eJudge `v3.14.0` и добавляет описание языка и адаптер посылок `.sbsl`. Дистрибутив 1С в репозиторий не входит. Базовая платформа по [официальной инструкции установки eJudge с нуля](https://ejudge.ru/wiki/index.php/Инсталляция_ejudge_3.10.0%2B_на_Ubuntu_22.04_с_нуля) — **Ubuntu 22.04 на x86_64**. Выполните её шаги 1–11, затем в шаге 12 собирайте **этот форк** вместо исходного репозитория eJudge. Параметры `./configure`, `make`, `make install` сохраните из официальной инструкции. Далее выполните её шаги 13–19, добавив настройку языка из разделов ниже после установки eJudge.

Если вам передали Git bundle, скопируйте его на сервер и замените команду `git clone` из шага 12:

```sh
git clone -b element-script-10.0.2-1 /путь/ejudge-element-10.0.2-1.bundle ejudge
cd ejudge
git log -1 --oneline
```

Убедитесь, что вы на ветке `element-script-10.0.2-1`. Git bundle содержит исходники и историю eJudge, но не содержит среду 1С.

На macOS с Apple Silicon штатный `Dockerfile` eJudge без `--platform linux/amd64` не собирается: он требует пакеты `i686`, которых нет в Fedora для ARM. Контейнерный способ развёртывания этого форка пока не проверен; для первой установки используйте Ubuntu 22.04 x86_64.

## 1. Установите среду 1С

Скачайте оригинальный **полный** дистрибутив 10.0.2-1 для Linux с [официального портала 1С](https://1cmycloud.com/console/help/lang/docs/topics/install-1c-script-runtime-environment/). Для варианта U нужна поддерживаемая Java (по документации 1С — JRE/JDK 11 или 17). Не публикуйте API-токен загрузки.

Установите Java 17 (`sudo apt install openjdk-17-jre-headless`). Распакуйте полный архив в `/opt/1c/element-script-10.0.2-1` так, чтобы файл `executor` находился непосредственно в этом каталоге, и проверьте:

```sh
/opt/1c/element-script-10.0.2-1/executor -v
```

Команда должна сообщить версию `10.0.2-1`. Проверьте её также от имени пользователя, выполняющего посылки eJudge: `sudo -u ejexec /opt/1c/element-script-10.0.2-1/executor -v`. Сохраните каталог `licenses` вместе с дистрибутивом. Каталог и вложенные файлы должны быть доступны на чтение этому пользователю; не открывайте на запись весь `/opt/1c`.

## 2. Зарегистрируйте язык в eJudge

После `make install` этого форка запустите штатный конфигуратор компиляторов от пользователя `ejudge`. Если eJudge установлен в `/opt/ejudge`, команда выглядит так:

```sh
sudo -u ejudge /opt/ejudge/bin/ejudge-configure-compilers --batch \
  --with-element=/opt/1c/element-script-10.0.2-1/executor
```

Проверьте, что создан файл `element.cfg` с `version="10.0.2-1"` и правильным `ELEMENTPATH`. Фактический каталог конфигурации и скриптов покажет `ejudge-configure-compilers --help`; они зависят от установки. При нестандартных путях используйте параметры `--enable-lang-config-dir` и `--enable-lang-script-dir`. Не перезаписывайте вручную существующую конфигурацию других языков.

## 3. Включите язык в турнире

В `serve.cfg` нужного турнира добавьте язык (ID 90 зарезервирован этим форком):

```ini
[language]
id = 90
short_name = "element"
arch = "linux-shared"
src_sfx = ".sbsl"
```

Не дублируйте существующий `id` или `short_name`. Перезагрузите конфигурацию турнира штатным средством eJudge. В форме отправки должен появиться «1С:Предприятие.Элемент Скрипт».

## 4. Проверьте на отдельном тестовом турнире

Для первого запуска возьмите [`examples/element/hello.sbsl`](../examples/element/hello.sbsl); он должен вывести `ELEMENT_OK`. Затем создайте в отдельном тестовом турнире задачу с этим ожидаемым выводом и отправьте пример, а также программу с неверным ответом. Убедитесь, что корректная посылка получает Accepted, неверная — Wrong Answer, а отчёт и исходный код доступны судье. Проверьте лимиты времени и памяти, параллельные посылки, права пользователя запуска и отсутствие доступа посылки к сети и файлам сервера. Адаптер не создаёт песочницу; он полагается на механизм изоляции eJudge. Не принимайте недоверенные посылки до этой проверки.

## Состав публикации

Исходники eJudge остаются под их исходной лицензией. Наши файлы — `scripts/element.in`, `scripts/element-version.in`, регистрация в `scripts/files.make` и `scripts/lang_ids.cfg`, этот документ и проверочный тест. Не добавляйте дистрибутив 1С, резервные копии, данные турнира, решения участников, задачи Polygon, пароли, ключи или токены. Перед публичной публикацией подтвердите право на вклад и лицензию наших файлов.
